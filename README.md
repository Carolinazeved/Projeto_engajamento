# Análise de Engajamento em Redes Sociais

Projeto desenvolvido em Python para análise de métricas de redes sociais.

## Tecnologias utilizadas
- Python
- Pandas
- Matplotlib

## Funcionalidades
- Leitura de dados CSV
- Cálculo de taxa de engajamento
- Geração de gráficos

## Objetivo
Demonstrar análise de dados aplicada ao marketing digital.
